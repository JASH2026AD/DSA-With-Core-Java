## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/JASH2026AD/DSA-With-Core-Java.git
```

Move into the repository:

```bash
cd DSA-With-Core-Java
```

Compile a Java program:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```
